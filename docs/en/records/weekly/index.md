# Weekly Notes

Recorded in units of "weeks": gather up the things you touched, the pitfalls you hit and the things you learned this week.

A week is not a long time, but when you flip back through it you can see quite clearly what you were busy with during that stretch, which is far more dependable than waiting until the end of the month to recall it.

> [!tip] How to Write
>
> It does not need to be long; a running account is fine. Writing down "what I did this week" is more valuable than "how well I did this week".
