# Introduction

# **What is Vue?**

Vue (pronounced /vjuː/, like **view**) is a JavaScript framework for building user interfaces. It builds on top of standard HTML, CSS, and JavaScript, and provides a declarative, component-based programming model that helps you develop user interfaces efficiently. Whether the interface is simple or complex, Vue can handle it.

# **The Progressive Framework**

Vue is a framework and an ecosystem. Its features cover most of the common needs of front-end development. But the web world is extremely diverse, and the things different developers build on the web can vary greatly in form and scale. With that in mind, Vue's design pays a lot of attention to flexibility and the idea of being "incrementally adoptable". Depending on your use case, you can use Vue in different ways:

- Enhance static HTML progressively, with no build step
- Embed as Web Components in any page
- Single-Page Application (SPA)
- Fullstack / Server-Side Rendering (SSR)
- Jamstack / Static Site Generation (SSG)
- Target desktop, mobile, WebGL, and even the terminal
