## Penetration Testing Knowledge Points

### Information Gathering

1. Fofa

   FOFA is a tool for cyberspace search; it can help users discover, collect, and organize publicly available information on the Internet. Through FOFA, security researchers or network security experts can query specific server information, technology stacks, and even more detailed technical configurations, which plays an important role in vulnerability discovery, asset inventory, and other aspects

2. Pikachu

   "*Pikachu range*" is a platform designed specifically for web penetration testing; it provides beginners and professionals with a safe environment in which they can try various attack methods and learn how to discover and fix vulnerabilities.
