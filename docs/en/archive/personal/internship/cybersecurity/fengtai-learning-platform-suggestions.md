# Suggestions for the Fengtai Learning Platform

### **Objectives**

1. **Improve professional skills**: Help learners master the basic theory, technical principles, and practical skills of the industrial control security field, including but not limited to industrial control system architecture, security threat identification, protection strategy formulation, and emergency response.
2. **Strengthen practical capability**: By simulating security incidents in real industrial control environments, let learners exercise their emergency response and handling capabilities in scenarios close to real operations.
3. **Promote knowledge updating**: As industrial control technology develops rapidly and security threats keep evolving, the platform needs to update course content regularly to ensure that learners can access the latest security technologies and protection concepts.
4. **Cultivate security awareness**: Through case analysis, security awareness education, and other means, raise learners' security awareness and sense of responsibility so that they can proactively identify and prevent security risks in their daily work.

### **Learning Formats**

1. **Online courses**: Provide video tutorials, and the course content should cover the fundamentals of industrial control security, advanced skills, and practical exercises.
2. **Virtual lab**: Build a virtual industrial control environment so that learners can carry out hands-on operations in a simulated environment, such as configuring security devices, writing security policies, and responding to security incidents. But the server load would probably be very heavy that way, so it is not very realistic
3. **Case analysis**: Collect and organize typical cases in the industrial control security field and analyze them in depth to help learners understand the causes, impact, and countermeasures of security threats. Simply put, it means reading blog posts and learning from the experience summarized by others
4. **Interactive discussion**: Set up a forum or community to encourage communication and interaction between learners and mentors, sharing what they have learned and discussing technical problems.

### **Core Module Function Design**

1. **Course center**
    - **Course system**: Build a complete industrial control security course system, including basic courses, advanced courses, and practical courses, to meet the needs of different learning stages.
    - **Course updates**: Update course content regularly to ensure that learners can access the latest security technologies and protection concepts.
    - **Course recommendations**: Based on the learner's learning history and interests, intelligently recommend related courses to improve learning efficiency.
2. **Virtual lab**
    - **Environment setup**: Provide virtual labs for a variety of industrial control environments, such as PLC control systems and SCADA systems, so that learners can carry out hands-on operations in a simulated environment.
    - **Experiment guidance**: Provide detailed operating instructions and points to note for each experiment to help learners complete the experiment tasks smoothly.
    - **Experiment records**: Record the learner's experiment process and results for easy review and summary.
3. **Case library**
    - **Case collection**: Widely collect typical cases in the industrial control security field, including both successful defenses and lessons from failures.
    - **Case analysis**: Analyze each case in depth and extract the causes, impact, and countermeasures of the security threat.
    - **Case sharing**: Encourage learners to share their own experience in handling security incidents to enrich the case library.
4. **Interactive community**
    - **Forum discussion**: Set up forum sections where learners can post questions, share insights, and exchange technical knowledge.
    - **Expert Q&A**: Invite company experts to join the community and provide learners with professional answers and guidance.
    - **Event organization**: Regularly organize online or offline technical exchanges, seminars, and other events to promote communication and cooperation among learners.
