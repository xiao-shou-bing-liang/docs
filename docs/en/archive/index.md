# Preface

After more than half a year, this is a restart. I thought the repository would vanish along with my GitHub account, but with a hint from the folks at the base I managed to get it back. The reason is a bit convoluted: during the "lobster rush" earlier this year, a lot of bot accounts were farming stars, and my account got banned for changing IP addresses too often. Appeals went nowhere, so I deleted the account and started over.

It has been a long time, and the past is hard to look back on; my mindset has changed a lot. What lives here are all old posts — the new ones start from scratch!
