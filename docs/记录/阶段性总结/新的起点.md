# 新的起点

时光倏忽而过，距上次提笔写总结已近一年。今日沉下心来梳理过往，想把从高考到如今的行迹与心绪落成文字，给这三年半的青春留一笔印记——也算没白走这一程。回头望，这一路铺满了遗憾，藏着数不清的狼狈，也悄悄攒着成长。

## 顺遂的学业，狼狈的自己

中考之前的人生，走得算得上顺风顺水。我循着父亲定下的目标一步步往前，小学与初中的课业不算繁重，我也算肯在学习上花心思，拿过年级第一，名次始终稳在前列，毫无悬念地考入了目标高中。

可学业之外的日子，我过得一塌糊涂。尤其是在感情与人际里，我自私又怯懦，后来所有的拉扯与落空，如今想来，都是自己种下的因果。

我一直是个不肯示弱的人。为了撑住体面，我撒过不少谎，常常被虚荣心推着硬扛，时至今日也偶尔会犯。我清楚撒谎不对，也总想做个坦荡诚实的人，可年少时的偏执与骄傲，终究还是伤了不少我本不想伤害的人。

## 隔着一层薄纱

最先想起的是我的好兄弟。初三那年，我抱着一股“想要改变”的莫名偏执，和他生出了嫌隙。疫情爆发前的期末考，我估分比他低，竟一个人蹲在冬天雨里的乒乓球台中央嚎啕大哭——那是我从小到大，唯一一次那样失态。

中考放榜，我超了统招线近三十分，名次比他高出不少。那一刻我心里有隐秘的快意，可随之而来的是挥之不去的失落。暑假里我特意去他家找他，想亲手解开这个心结。后来他凭着定向生名额，和我进了同一所高中，分科前我们是隔壁班，分科后竟成了同班。

命运的巧合总让人唏嘘。我早已放下当初的较劲，却始终没勇气和他开诚布公地聊起过往。我们之间，终究像隔了一层薄纱，再也回不到当初的毫无芥蒂。

## 无疾而终的心动

还有她。我总因为所谓的面子拉不下脸道歉，直到现在也偶尔会梦到她，我自己也说不清缘由，或许从2017年9月第一眼见到她时，心动就已经开始了。

在大人眼里，初中生的恋爱不过是过家家，可落在自己身上，每一份情绪都真切得发烫。最开心的日子都在故事前半段：和她慢慢聊天，一点点拉近距离，那时学业也顺风顺水，在一千多人的年级里考到第一，我难免有些飘飘然。长相普通的我，因为小学时被女生表白过，竟生出些盲目的自信，于是在运动会上和她表了白，我们就这样在一起了。

可这段关系只维持了两个多月。期末考我没能守住年级第一的名次，父亲又翻了我的QQ聊天记录，发现了我们谈恋爱的事。在他的劝说下，我以“要以学习为重”为借口，在QQ上和她提了分手。隐私被摊开在父母面前的窘迫，加上年少时混沌的判断力，让我轻易就接受了那些“理所当然”的约束。

分手后她对我印象很差，我厚着脸皮去找她复合，她竟也同意了。可没过多久，因为我自身的问题，她再次提出了分手。那天她扭扭捏捏地来找我，话到嘴边又咽下，我猜得到她想说什么，也就顺水推舟地分了手。后来我才知道，她很快就有了新的恋情，而我还被蒙在鼓里，甚至一次次放下身段去求复合。更戏剧的是，她后来和我那位好兄弟走到了一起。

那段日子我像见不得光的人，反复窥探她的朋友圈。直到大学时再听闻她的消息，她已经坐在别人的副驾驶上，也考上了东北大学，而我只是读了一所双非院校。落差感涌上来的那一刻，我才真切地意识到，有些人和事，早就停在过去了。

## 向内行走

高中三年，整体算得上安稳，却也让我很难再对谁动心——中间也遇见过让我产生错觉的女生，如今想来都无足轻重。更重要的是，高中时我开始学着向内看，一点点看清自己本来的样子，也试着直面自己的缺点。

我不得不承认，自己的天资十分有限。和身边优秀的同学比，我悟性差了一大截，也从没有全身心扑在学习上。日子过得松散，打打球、看看书，到了高三，甚至每晚在床上用手机看漫画、追动漫。所以高考考出那样的分数，其实早有预兆，没什么可委屈的。

但康杰中学的老师与同窗，至今想起仍是青春里最暖的底色。尤其感谢李江老师！

## 志愿与一场误会

高考分数出来后，志愿填报成了难题。211院校我不敢奢望，太原理工其实稳上，但我一心想出省看看外面的世界。作为运城人，我此前去过最远的地方不过是西安。

机缘巧合下，我被桂林电子科技大学数学与计算科学学院的信息与计算科学专业录取。查到录取结果的那一刻，我整个人是懵的——因为自己的疏忽，我原以为这是计算机专业，入学才知道是数学与计算机的交叉学科，好在整体也不算差，便也安下心来。

## 从零开始

刚踏进大学校门那天我就清楚，学历这道差距已经拉开，再松下去只会被甩得更远。所以这三年多，我一直在往前赶，抢机会，也想补一补年少时留下的那些遗憾。

刚好赶上疫情结束，我见到了桂电有史以来最大规模的军训，至少三届同训。起初只是普通训练，有天校武装部的同学过来摇人，说他们那边专练战术动作，会累一些，也苦一些。我二话没说就去了。后来分进医疗班，认识了几个朋友。事后看，跟我一起练战训的没有等闲之辈：一个是机电学院的年级长，保研去了山东大学；一个是校 ACM 基地的主席，前不久刚在成都场拿了铜牌。

那阵子被医疗班的卡密忽悠得不轻，他吹什么我都当真，新人嘛。不过他也确实给我制造了焦虑，逼着我认真想该选哪个计算机方向。眼光有限，校级实验室不敢想，只能在本院的实验室和社团里挑，最后挑了创新基地。

进基地要考核。我一个没学过计算机的人，只能自己啃 C 语言。这里得提醒一句，鹏哥的课不用看，纯属浪费时间，看了一堆也记不住。后来买了本《C Primer Plus》，国庆五天，把指针、结构体之前的内容全啃完了。同一时期还在院田径队备战校运会，日子过得倒挺充实。考核轻轻松松就过了。也是在那时候定下往网安走，可基地的学长也说不清这方向该怎么学，我只能先把计算机的基础补上。

进基地后的第一个考核，是把个人博客搭起来。当初折腾的是 hexo。我和前端的第一面，就是从这儿见的。

过完年，为了把网安学明白，我开始补 Linux、计网和数据结构。也是这时候，偶然看到工控安全实验室在招人。条件上写着每月至少八百块，又听说里面都是网安、信安、密码学专业的人，我动了心。考核所有人都得从头开始，在指定平台上自学半个月，我也学了半个月，最后有惊无险杀进线下赛。线下赛有打靶场的实操题，我一张白纸，好在靶场环境出了毛病，没人做得出来。我凭一身狗运，靠选填和问答题拿了第六名，群面也过了，就这么进了工控安全实验室。里面几乎全是招大二有基础的，我们这届只有三个大一的。

我选了逆向。这条路也伴着疼。实验室氛围很怪，大家互相不知道对方在做什么，谁都捂着自己的底。我去问逆向的大二学长该怎么学，他含糊其辞。倒是一个大四学长说，一定要多写博客，想练逆向就试着手搓一个操作系统。现在想，这是我那几年听过最好的建议。

但我到底没坚持下来。转去学了王爽老师的《汇编语言》，又在那个暑假，在自己电脑上跑起了 ollama。把模型点开，能一问一答，我就觉得挺新鲜。至于这东西将来会动到谁的饭碗，我一点没往那上面想。同一时期还折腾装机、多系统，尤其爱捣鼓 arch linux。那阵子是真开心。

也是从这时开始往健身房跑。这方面我比一般人有点天赋。当然，也给后来的身体问题埋了伏笔。

## 转向的代价

大二上，让我爸给我配了台式机。那段时间沉迷烧耳机，逆向却越学越迷糊。导师工作忙，我们四个逆向组的又不好意思去打扰，好不容易打扰一次，他直接甩过来一份 wifi 固件，让我们逆向找漏洞。我连 IDA Pro 都还没用明白，当场就傻在那儿。后来烽台的 hr 来谈话，李硕和覃嘉嘉都在这个时候退了。我想着一个月还有八百块，就继续混着。期间也短暂试过渗透，可安全这块到底没什么长进。

这学期跟着别人练力量，算有点小成果。精力大半放在课外，代价是挂了数学分析3和概率论与数理统计。我很清楚不能再这样下去，得找个破局的办法。

寒假跟亲戚（bg双九华为）聊过一次。聊完，我心里隐隐定下了学软件开发的目标。只是那阵子 deepseek r1 还没出来，ai 只能写点函数，我也不觉得它能替代程序员。现在回头看，这个判断错得离谱。加上我本来就偏爱前端，就选了前端开发。

大二下赶在创新基地换届之前，我极限搓了一个管理系统出来，vue3，纯前端 mock 的假数据。就靠这个，当上了软件部副部长。其余时间都在琢磨云服务器到底怎么用，运维的东西学了不少，也亲手实践了很多，跟着覃嘉嘉学了很多。

就这样到了学期中。工控安全实验室招新，烽台的 hr 又来了，双选会也摆上了摊。这一次我跟她说了自己在做前端，正好烽台招前端，她就把我对接到了电力事业部，跟着做网络靶场项目的维护。也就这样认识了王立恒和邓志波。邓志波尤其知无不言，断断续续陪我聊到现在，一年半了。他教了我太多，我一直不知道该怎么谢他。

可同期也接连碰壁。大创被人耍了，烽台 hr 口头答应的暑期线下实习也放了鸽子。这两件事我是真没招，只能无能狂怒。顺带还挂掉了大学物理和数值分析。

身体上更是一塌糊涂。那阵子感冒咳嗽，几乎停训，吃得又多，体重一路涨过一百公斤。快放暑假时，腰五骶一髓核脱出，难受得厉害。小学期给大一上完课，我就回家了。

## 重修与第一次面试

身体和精神都磨了一轮，暑假过完回校，我开始专门学后端。那年课业也压着，四门挂科必须全部重修，不然连毕业都悬。我只能硬挤时间学开发，这次是真得把全栈啃下来。也接手了学情管理系统，一个人把项目的轮廓手搓了出来。

同时创新基地开始招新，我组织了培训。这期间出了些不愉快的事。王博丰，这个人我大概是忘不掉了。好心帮忙，反被咬了一口。我是真没招。往后我也不打算再对新人有这份热情了。

也迎来了第一次正经的实习面试，面得一塌糊涂，基础的东西根本答不上来。之后的时间基本都在复习备考。好在数学分析3、概率论与数理统计、大学物理都过了，数值分析拖到大三下也过了，四门重修全部清完，正修课程也全过。只是太久没练，人又胖回去，加上吃得咸、油重、饮料不断，身体已经撑到了边上。

## 身体先垮了

2025年12月18日，头晕头痛了好几天，早上五点多就醒，再也睡不着。想起奶奶脑梗的前兆，我直接去了桂林市人民医院，先挂神经内科，后转心脏内科。一量血压，高压160、低压100、心率120。心电图出来，窦性心动过速、T波改变。头部ct、心脏彩超、肾上腺彩超、双肾彩超都未见异常。抽了几管血，肝肾功能损伤，糖化血红蛋白高，同型半胱氨酸高。再测一次，血压降到140/100，心率90。医生只说，回去减肥，把嘴管住。

同时还查出肛瘘，必须手术。我不知道该怎么跟父母交代。在火车上给我爸发消息，没忍住，无声地哭了。那是我第一次真切觉得命要紧——我还想活着。

到了运城市人民医院，血检还是一堆问题。我这种情况不能动刀，得先保肝。那几天在医院，人消极到了极点，也是第一次看清自己的身体到底成了什么样，知道自己必须管住自己了。住院期间一直吃硝苯地平控释片压着血压。

手术顺利。只是我不想再打麻药了。半麻的时候，下半身像不是自己的，我在床上使劲抬腿，使劲想尿出来，喝了一瓶奶，一点水，像重新活了一遍。

出院回家，药就停了。到3月13日去学校前，体重减了15kg，指标也大幅好转。

## OpenClaw 那一波

寒假刚好赶上 OpenClaw 那一波。我开始正经玩 vibecoding，各种各样的 agent 都试过，正经产出只有一条：astrbot agent 的教学视频，截至目前在 B 站有1.4万播放。同时啃前端面经。我到现在也认为，面经不是八股，它确确实实能把前端基础夯得更实。那时我想着，回学校之后一定要拿下一份实习，不然到了秋招就晚了。

## 第一次实习

回校之后，课业走不开，只能在桂林本地投。没想到一面就过了，进了桂林瑞威赛德科技有限公司，从3月23日做到8月31日。杨奥辉去了力港网络，两家公司离得不远，我们就在中间地带合租了套两室一厅，一个月八百，冰箱空调该有的都有。缺点是七楼顶层，边上就是铁路，夜里过火车。我一开始恰好睡在铁路那侧，根本睡不好，血压又上来了。四月起，只能开始吃硝苯地平缓释片10mg。

实习的日子平平常常。技术上长进不多，基础的增删改查倒是写得更顺了。平时偶尔跟老赵吵吵架、斗斗嘴。总的来说过得不快乐，学校公司两头跑，是真的累。

期末考在学校待了半个月，之后又回公司。杨奥辉从力港网络跑路了，我只好自己再去找小房子。这时血压又不稳，缓释片压不住，七月起换成硝苯地平控释片。还长了智齿，牙疼；肠胃也出毛病，没胃口，吃多一点就想吐；结膜炎也犯了，眼睛难受。医院又花掉不少钱。可检查下来，肾功保住了，糖化降了，肝功也回来了，体重再掉10kg，到80kg。

在公司也不好过。我几乎不怎么写代码，主要写文档、做性能测试、跑对接。后来三方测评驻场保完障，老赵找我谈话，受益良多。他把我实习期间暴露的问题一条条摆出来，也给了些很实在的建议。我顺势提出要离职去秋招。本来打算9月23日走，凑满半年，但他说工资结算麻烦，加上可能本身也不太想见我，就让我赶在九月前走。走的时候，三方还没测完。

结工资还被摆了一道，扣了2500，我只拿到500。另外三个实习生都是正常3000。不过好在我跑得早，那三位一直待到十月中旬。

## 没看懂它

现在回头看，AI 这条线其实贯穿了整个大学，只是我当时看不出来。

最早是2024年暑假，在自己电脑上跑 ollama，那会儿连 r1 都还没有。后来聊起 ai，我还笃定它只会写函数，替代不了程序员。真正让我惊到的是2026年初 OpenClaw 那一波，agent 能把一整块活干完，我从“玩玩看”变成了天天用。可即便到那时，我也只把它当工具，从没算过它要动的到底是什么。

等到秋招才明白，动的是岗位本身。27届秋招里，前端的坑肉眼可见地少了。

我是同届里最早碰到它的那批人，却是最晚看懂的那批。

## 秋招与此刻

回校歇了几天，我买了好几本 Java 的书，打算学微服务，背背后端八股。可面了几家技术岗，这个念头就彻底打消了。说是招全栈，其实几乎只看后端，前端如何根本没人问。我去投销售类岗位，被来回拷打，最后只能梭哈荣耀的服务解决方案管培生。到现在还在池子里泡着，从10月19日入池到11月3日，一点消息都没有。前几天跟杨奥辉去湖边聊了一早上，回顾这三年多，愈发觉得迷茫。路在何方？

可写到这儿，我反倒没那么慌了。

这三年半，我把能试的都试了一遍：从零啃 C 语言，考进实验室，做管理系统，当副部长，带培训，跑实习，减掉近三十公斤，还在网上做教学视频收获一万四的播放量。没有一样做到顶尖，但也没有一样是白做的。那些狼狈是真的，可它们至少证明我没在原地待着。

路确实还没走通。但我才二十出头，手上的东西比三年前多得多，身体比一年前好得多，也终于知道自己不会什么、想要什么。

所谓新的起点，大概不是重新开始，而是带着这些继续往下走。

最近又开始练了。隔天去一次健身房，先把状态一点点捡回来。身体是头一个垮的，那就先从它补。

十月十九号去长沙面荣耀的终面，面完顺路去了趟橘子洲，那两张就是当天拍的。剩下三张是国庆跟同学出去的。都随手拍的，算是给现在的自己留个记录。
