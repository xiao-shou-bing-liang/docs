# 阶段性总结

以「阶段」为单位记录，一段相对完整的时间走完之后，回头做个总结。

阶段比月长、比学期短，说的东西也应该比周志和月志重一些——做了什么、拿到了什么、踩了什么坑、下一步往哪走。
