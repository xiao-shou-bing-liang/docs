# 周志

以「周」为单位记录，把这一周碰过的事情、踩过的坑、学到的东西攒下来。

一周的时间不长，但回头翻的时候能很清楚看出这段时间自己在忙什么，比等到月底再回忆要靠谱得多。

> [!tip] 怎么写
>
> 不用长，流水账就行。记下来「这周做了什么」比「这周做得多好」更有价值。
