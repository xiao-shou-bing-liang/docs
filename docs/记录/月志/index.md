# 月志

以「月」为单位记录，把这个月做过的事情、做过的东西收个尾。

周志记得碎，月志记得全，一般是月底回头翻一遍这个月的周志，把值得留下来的东西拎出来，顺手把下个月要做什么也定下来。

> [!tip] 怎么写
>
> 一句话总结这个月的主题，然后分「做了」「学到了」「下个月」三段就够了。
