# indexConfig文件夹

这个文件夹里放的是动态首页的综管后台

## 基本逻辑

1. index.vue
    
    是一个 Vue 3 组件，主要功能是展示一个标签页界面，允许用户在“系统介绍”和“业务板块”两个标签页之间切换。
    
2. applicationLink.vue
    
    此文件主要用于管理应用链接，包含列表展示、新建、编辑和删除应用链接等功能
    
3. systemDesc.vue
    
    此文件主要用于管理系统描述，包含列表展示、新建、编辑系统描述等功能。
    
4. businessPlate.vue
    
    该文件主要用于管理业务板块，包含列表展示、新建、编辑和删除业务板块等功能。

```html
<template>
  <el-card class="indexConfig-container">
    <!-- 标签页组件，通过 v-model 绑定当前激活的标签 -->
    <el-tabs v-model="activeName" class="demo-tabs">
      <!-- 使用 v-for 动态生成标签页 -->
      <el-tab-pane
          v-for="[key, tab] in Object.entries(TAB_OPTIONS)"

          :label="tab.label"
          :name="tab.key"

        <!-- 根据当前激活的标签，动态渲染对应的组件 -->

      </el-tab-pane>
    </el-tabs>
  </el-card>
</template>
```

```html
<script setup>
// 导入所需组件和函数
import TableComponent from "@/components/table/TableComponent.vue";
import {onMounted, onUnmounted, reactive, ref, shallowReactive, watch} from "vue";
import { setObjectValue, xtend} from "@/utils/common";
import {instanceToPlain} from "class-transformer";
import { getApplicationLinkApi, delApplicationLinkApi, addApplicationLinkApi, updateApplicationLinkApi } from "@/api/indexConfig";
import {ApplicationLinkList} from "@/view/superAdmin/defaultConfig";
import { ElMessage, ElMessageBox } from "element-plus";
import {emitter} from "@/utils/bus";
import {get} from "@/api";
import {setHTMLSize} from "../../../utils/rem";

// 定义响应式数据
const state = shallowReactive({
  tableData: []
});
let businessItem = {};

// 表格分页相关
const tableRef = ref(null);
const pageInfo = ref(null);

// 表单相关
const isAdd = ref('');
const visibleLink = ref(false);
const visible = ref(false);
const formRef = ref(null);
const form = reactive({
  applicationID: null,
  name: '',
  link: ''
});

// 表单验证规则
let rules = {
  name: [{ required: true, message: '应用名称不能为空', trigger: 'blur' }]
};

// 关联应用列表
const applicationList = ref([]);

// 获取应用链接列表
const getApplicationLink = async () => {
  const res = await getApplicationLinkApi(businessItem.ID, {});
  state.tableData = res.data || [];
  tableRef.value.setPageInfo({ total: res.data.length, page: 1, pageSize: 9999 });
}

// 设置分页信息并重新获取数据
const setPageInfo = arg => {
  pageInfo.value = arg;
  getApplicationLink();
};

// 初始化页数据
const getDefaultPage = page => {
  pageInfo.value = page;
};

// 表格操作列按钮配置
const optionButton = [
  {
    link: true,
    type: 'warning',
    name: '编辑',
    click: arg => {
      isAdd.value = 'edit';
      visible.value = true;
      setObjectValue(form, arg);
      form.id = arg.id;
      if (!form.applicationID) {
        form.applicationID = null;
      }
    },
  },
  {
    link: true,
    type: 'danger',
    name: '删除',
    click: arg => {
      ElMessageBox.confirm(`删除应用链接 【${arg.name}】  ，删除后将不可恢复！`, '删除应用链接', {
        confirmButtonText: '删 除',
        cancelButtonText: '取 消',
        type: 'warning',
        center: true,
        customClass: 'delMessageBox',
        confirmButtonClass: 'delButtonClass',
      }).then(async () => {
        delApplicationLinkApi(businessItem.ID, arg.id).then(res => {
          if (!(res instanceof Error)) {
            ElMessage.success(`删除成功!`);
            getApplicationLink();
          }
        });
      });
    },
  },
];

// 新建应用链接
const addApplicationLink = () =>{
  isAdd.value = 'add';
  visible.value = true;
}

// 关联应用 ID 变化时更新表单数据
const appIDChange = () =>{
  if(form.applicationID) {
    for(let i = 0;i < applicationList.value.length;i++) {
      if (applicationList.value[i].ID === form.applicationID) {
        form.name = applicationList.value[i].name;
        form.link = applicationList.value[i].callbackAddress;
        break;
      }
    }
  } else {
    form.name = '';
    form.link = '';
  }
}

// 确认新建或编辑操作
const addOrEditBusinessPlate = () => {
  formRef.value?.validate(async valid => {
    if (valid) {
      if (isAdd.value === 'add') {
        if(!form.applicationID) {
          delete form.applicationID;
        }
        addApplicationLinkApi(businessItem.ID, form).then(res => {
          if (!(res instanceof Error)) {
            ElMessage.success(`${res.msg}`);
            visible.value = false;
            getApplicationLink();
          }
        });
      } else {
        if(!form.applicationID) {
          delete form.applicationID;
        }
        updateApplicationLinkApi(businessItem.ID, form.id, form).then(res => {
          if (!(res instanceof Error)) {
            ElMessage.success(`${res.msg}`);
            visible.value = false;
            getApplicationLink();
          }
        });
      }
    }
  });
};

// 打开应用链接列表对话框
const openApplicationLinkDialog = (item) =>{
  visibleLink.value = true;
  businessItem = item;
  getApplicationLink();
}

// 监听表单对话框显示状态
watch(
    visible,
    async () => {
      if (!visible.value) {
        form.applicationID = '';
        form.name = '';
        form.link = '';
      } else {
        let res = await get(
            {
              page: 1,
              pageSize: 9999
            },
            "/general/app/"
        );
        applicationList.value = res.data?.list;
      }
    },
    { immediate: false },
);

// 监听事件总线的消息
emitter.on('application-link', openApplicationLinkDialog);

// 组件挂载时执行
onMounted(() =>{
  // 此处无具体逻辑
})

// 组件卸载时移除事件监听
onUnmounted(() =>{
  emitter.off('application-link', openApplicationLinkDialog);
})
</script>
```

## 基本逻辑

从代码来看，这是一个 Vue 3的单文件组件，作为整个系统的首页展示。以下是它的基本逻辑分析：

1. **页面结构**：
    - 顶部有固定导航栏(`zg-index-header`)
    - 中间是轮播图区域(`zg-index-banner`)
    - 下方分为4个主要业务板块：
        - 人才培养
        - 跨域互联
        - 漏洞挖掘
        - 安全测试
    - 底部有页脚信息
2. **核心功能逻辑**：
    - **数据获取**：在`onMounted`生命周期中，通过API获取系统介绍(`getSystemDescFilterApi`)和业务板块详情(`getBusinessPlateDetailApi`)
    - **权限控制**：检查cookie中的`sso_token`判断用户登录状态，并根据用户权限(`userApps`)控制不同功能模块的访问
    - **导航交互**：
        - 顶部导航栏有搜索、用户头像下拉菜单
        - 中间区域有锚点导航，点击可平滑滚动到对应板块
        - 各业务板块有hover效果和点击跳转
3. **主要业务逻辑**：
    - **人才培养**：展示5个子模块(培训教学、竞技实训等)，根据权限控制访问
    - **跨域互联**：展示系统介绍和查看详情入口
    - **漏洞挖掘**：展示4个安全系统入口
    - **安全测试**：展示11种安全测试工具入口

这个页面作为系统门户，集成了各主要业务入口，并通过动态数据展示和权限控制提供了良好的用户体验。

# 俩页面数据关联

`indexConfig`文件夹与`zgIndex.vue`主要通过API调用关联起来。具体关联方式如下：

1. **API定义部分**（`src\api\indexConfig`）：
    
    index.js文件：
    
    ```jsx
    // 定义获取业务板块详情的API
    export const getBusinessPlateDetailApi = () => {
      return request({
        url: '/general/system/businessPlate/detail',
        method: 'get'
      })
    }
    
    // 定义获取系统介绍的API
    export const getSystemDescFilterApi = () => {
      return request({
        url: '/general/system/desc/filter',
        method: 'get'
      })
    }
    ```
    
2. **组件调用部分**（`src\view\zgIndex`）：
    
    index.vue
    
    ```jsx
    // 导入API
    import { getBusinessPlateDetailApi, getSystemDescFilterApi } from "@/api/indexConfig";
    
    // 在onMounted生命周期中调用
    onMounted(() => {
      // 获取系统介绍
      getSystemDescFilterApi().then(res => {
        // 处理返回数据...
      });
    
      // 获取业务板块详情
      getBusinessPlateDetailApi().then(res => {
        // 处理返回数据...
      });
    })
    ```
    
3. **数据流关联**：
    - `zgIndex.vue`作为首页组件，通过调用`indexConfig`中定义的API获取配置数据
    - 获取的数据用于渲染：
        - 轮播图内容（baseInfoArr）
        - 四大业务板块信息（人才培养/跨域互联/漏洞挖掘/安全测试）
        - 各板块下的子模块链接
4. **功能实现**：
    - `indexConfig`提供后端接口的抽象层
    - `zgIndex.vue`负责数据获取和界面渲染
    - 通过Pinia/Vuex管理共享状态（如用户权限信息）

这种设计遵循了前后端分离的原则，使配置数据的获取与界面渲染解耦，便于维护和扩展。
