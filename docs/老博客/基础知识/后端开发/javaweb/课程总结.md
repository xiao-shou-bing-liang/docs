## logback.xml

这个配置文件的命名一定要按照这个名字来因为约定如此并且不用作多余的操作就能生效,你只需要写好这份配置文件即可

这个配置文件的作用就是控制控制台的日志输出并把输出保存为log日志文件

还需要强调一个东西是@Slf4j这个注解是Lombok库中的东西并不是springboot里面的

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- Logback日志框架配置文件：用于定义日志的输出方式、格式和存储策略 -->
<configuration>
    <!-- 1. 控制台日志输出器（命名为STDOUT） -->
    <!-- ConsoleAppender：Logback提供的控制台输出组件，负责将日志打印到控制台 -->
    <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender">
        <!-- 编码器：定义日志输出的格式 -->
        <encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
            <!-- 日志格式说明：
                 %d{yyyy-MM-dd HH:mm:ss.SSS}：日志产生的时间（精确到毫秒）
                 [%thread]：当前线程名称
                 %-5level：日志级别（左对齐，占5个字符宽度，如INFO、ERROR）
                 %logger{50}：日志所属的类/日志器名称（最多显示50个字符，超出省略）
                 %msg%n：日志具体内容 + 换行符 -->
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{50} - %msg%n</pattern>
        </encoder>
    </appender>

    <!-- 2. 文件滚动日志输出器（命名为FILE） -->
    <!-- RollingFileAppender：Logback提供的文件输出组件，支持日志文件自动拆分（滚动） -->
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
        <!-- 滚动策略：定义日志文件何时/如何拆分 -->
        <!-- SizeAndTimeBasedRollingPolicy：按时间+文件大小双重条件拆分日志 -->
        <rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">
            <!-- 日志文件命名规则：
                 log/：日志文件存储的目录（项目根目录下的log文件夹）
                 %d{yyyy-MM-dd}：按日期分组（每天一个基础文件名）
                 %i：同一天内文件拆分的序号（从0开始，如log.2023-10-05.0.log、log.2023-10-05.1.log） -->
            <fileNamePattern>log/log.%d{yyyy-MM-dd}.%i.log</fileNamePattern>
            <maxFileSize>10MB</maxFileSize> <!-- 单个日志文件的最大容量，超过则自动创建新文件 -->
            <maxHistory>30</maxHistory>      <!-- 日志文件保留天数，超过30天的旧日志会自动删除 -->
            <totalSizeCap>1GB</totalSizeCap> <!-- 所有日志文件的总容量限制，超过1GB会删除最旧的日志 -->
        </rollingPolicy>

        <!-- 文件日志编码器：格式与控制台保持一致，便于前后端日志对照排查问题 -->
        <encoder class="ch.qos.logback.classic.encoder.PatternLayoutEncoder">
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{50} - %msg%n</pattern>
        </encoder>
    </appender>

    <!-- 3. 根日志器配置：控制整个项目的日志输出行为 -->
    <root level="INFO"> <!-- 全局日志级别：只输出INFO及以上级别日志（INFO/WARN/ERROR），忽略DEBUG/TRACE -->
        <appender-ref ref="STDOUT" /> <!-- 引用控制台输出器，日志同时输出到控制台 -->
        <appender-ref ref="FILE" />   <!-- 引用文件输出器，日志同时输出到文件 -->
    </root>
</configuration>
```

## Controller

Controller层就是在没有过滤器跟拦截器的情况下请求进来的第一层也是响应返回的最后一层我自认为我这里的代码写的还是比较规整的

```java
package xyz.cmcy.controller;

import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import xyz.cmcy.pojo.PageResult;
import xyz.cmcy.pojo.Result;
import xyz.cmcy.pojo.Student;
import xyz.cmcy.pojo.StudentQueryParam;
import xyz.cmcy.service.StudentService;

import java.util.List;

@Slf4j
@RestController
@RequestMapping("/students")
public class StudentController {
    @Autowired
    private StudentService studentService;

    @GetMapping
    public Result page(StudentQueryParam studentQueryParam){
        log.info("分页查询学生，参数：{}", studentQueryParam);
        PageResult<Student> pageResult = studentService.page(studentQueryParam);
        return Result.success(pageResult);
    }
    @DeleteMapping("/{ids}")
    public Result delete(@PathVariable List<Integer> ids){
        log.info("删除学生:{}", ids);
        studentService.delete(ids);
        return Result.success();
    }
    @PostMapping
    public Result save(@RequestBody Student student){
        log.info("保存学生:{}", student);
        studentService.save(student);
        return Result.success();
    }
    @GetMapping("/{id}")
    public Result getInfo(@PathVariable Integer id){
        log.info("查询学生:{}", id);
        Student student = studentService.getInfo(id);
        return Result.success(student);
    }
    @PutMapping
    public Result update(@RequestBody Student student){
        log.info("更新学生:{}", student);
        studentService.update(student);
        return Result.success();
    }
    @PutMapping("/violation/{id}/{score}")
    public Result updateScore(@PathVariable Integer id, @PathVariable Short score){
        log.info("违纪处理:{},{}", id, score);
        studentService.updateScore(id, score);
        return Result.success();
    }

}
```

## Service

在Spring Boot中，Service层采用“接口（如StudentService）+实现类（如StudentServiceImpl）”的结构，是为了遵循面向接口编程思想，通过接口定义功能规范、实现类处理具体逻辑，从而降低代码耦合度；这种设计便于后续扩展（可新增实现类而不修改调用方），能更好地支持Spring的AOP等特性（依赖接口生成动态代理），同时使代码职责更清晰，利于团队协作和单元测试，是企业级开发中提升代码灵活性与可维护性的最佳实践。

```java
package xyz.cmcy.service.impl;

import com.github.pagehelper.Page;
import com.github.pagehelper.PageHelper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import xyz.cmcy.mapper.StudentMapper;
import xyz.cmcy.pojo.PageResult;
import xyz.cmcy.pojo.Student;
import xyz.cmcy.pojo.StudentQueryParam;
import xyz.cmcy.service.StudentService;

import java.time.LocalDateTime;
import java.util.List;

@Service
public class StudentServiceImpl implements StudentService {
    @Autowired
    private StudentMapper studentMapper;

    @Override
    public PageResult<Student> page(StudentQueryParam studentQueryParam) {
        PageHelper.startPage(studentQueryParam.getPage(), studentQueryParam.getPageSize());
        List<Student> studentList = studentMapper.list(studentQueryParam);
        Page<Student> p = (Page<Student>) studentList;
        return new PageResult<Student>(p.getTotal(), p.getResult());
    }

    @Override
    public void delete(List<Integer> ids) {
        studentMapper.deleteByIds(ids);
    }

    @Override
    public void save(Student student) {
        student.setCreateTime(LocalDateTime.now());
        student.setUpdateTime(LocalDateTime.now());
        studentMapper.save(student);
    }

    @Override
    public Student getInfo(Integer id) {
        Student studentInfo = studentMapper.getInfo(id);
        return studentInfo;
    }

    @Override
    public void update(Student student) {
        student.setUpdateTime(LocalDateTime.now());
        studentMapper.updateById(student);
    }

    @Override
    public void updateScore(Integer id, Short score) {
        studentMapper.updateScore(id, score);
    }
}
```

## Mapper

### StudentMapper

```java
package xyz.cmcy.mapper;

import org.apache.ibatis.annotations.Insert;
import org.apache.ibatis.annotations.MapKey;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Options;
import xyz.cmcy.pojo.Student;
import xyz.cmcy.pojo.StudentQueryParam;

import java.util.List;
import java.util.Map;

@Mapper
public interface StudentMapper {
    List<Student> list(StudentQueryParam studentQueryParam);

    void deleteByIds(List<Integer> ids);

    @Options(useGeneratedKeys = true, keyProperty = "id")
    @Insert("insert into student(name, no, gender, phone, id_card, is_college, address, degree, graduation_date, clazz_id, create_time, update_time)\n" +
            "values (#{name},#{no},#{gender},#{phone},#{idCard},#{isCollege},#{address},#{degree},#{graduationDate},#{clazzId},#{createTime},#{updateTime})")
    void save(Student student);

    Student getInfo(Integer id);

    void updateById(Student student);

    void updateScore(Integer id, Short score);

    @MapKey("name")
    List<Map<String, Object>> getStudentDegreeData();
}
```

在该 `StudentMapper` 接口中，带有 `@Insert` 等注解的方法（如 `save` 方法）直接通过注解编写了 SQL 逻辑；而未被任何 MyBatis 注解（如 `@Select`、`@Update`、`@Delete`）修饰的方法（如 `list`、`deleteByIds`、`getInfo`、`updateById`、`updateScore`、`getStudentDegreeData`），其对应的 SQL 语句则需要在配套的 MyBatis XML 映射文件中进行配置和编写。

### xyz.cmcy.mapper

这个包是在resources文件夹下面的

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="xyz.cmcy.mapper.StudentMapper">
    <update id="updateById">
        update student set name = #{name},
        no = #{no},
        gender = #{gender},
        phone = #{phone},
        id_card = #{idCard},
        is_college = #{isCollege},
        address = #{address},
        degree = #{degree},
        graduation_date = #{graduationDate},
        clazz_id = #{clazzId},
        update_time = #{updateTime}
        where id = #{id}
    </update>
    <update id="updateScore">
        update student set violation_score = violation_score + #{score}
        where id = #{id}
    </update>
    <delete id="deleteByIds">
        delete from student where id in
        <foreach collection="ids" item="id" separator="," close=")" open="(">
            #{id}
        </foreach>
    </delete>
    <select id="list" resultType="xyz.cmcy.pojo.Student">
        select * from student s
        <where>
            <if test="name != null and name != ''">
                and s.name like concat('%',#{name},'%')
            </if>
            <if test="degree != null">
                and s.degree = #{degree}
            </if>
            <if test="clazzId != null">
                and s.clazz_id = #{clazzId}
            </if>
        </where>
        order by s.update_time desc
    </select>
    <select id="getInfo" resultType="xyz.cmcy.pojo.Student">
        select * from student where id = #{id}
    </select>
    <select id="getStudentDegreeData" resultType="java.util.Map">
        select (case
        when degree = 1 then '初中'
        when degree = 2 then '高中'
        when degree = 3 then '大专'
        when degree = 4 then '本科'
        when degree = 5 then '硕士'
        else '其他' end) name,
        count(*) value
        from student
        group by degree
        order by value
    </select>
</mapper>
```

```java
        String bucketName = aliyunOSSProperties.getBucketName();
        String region = aliyunOSSProperties.getRegion();

        EnvironmentVariableCredentialsProvider credentialsProvider = CredentialsProviderFactory.newEnvironmentVariableCredentialsProvider();

        String dir = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy/MM"));

        String newFilename = UUID.randomUUID() + originalFilename.substring(originalFilename.lastIndexOf("."));
        String objectName = dir + "/" + newFilename;

        ClientBuilderConfiguration clientBuilderConfiguration = new ClientBuilderConfiguration();
        clientBuilderConfiguration.setSignatureVersion(SignVersion.V4);
        OSS ossClient = OSSClientBuilder.create()
                .endpoint(endpoint)
                .credentialsProvider(credentialsProvider)
                .clientConfiguration(clientBuilderConfiguration)
                .region(region)
                .build();

        try {
            ossClient.putObject(bucketName, objectName, new ByteArrayInputStream(content));
        } finally {
            ossClient.shutdown();
        }

        return endpoint.split("//")[0] + "//" + bucketName + "." + endpoint.split("//")[1] + "/" + objectName;
    }
}
```

# Jwt登录认证 + 请求拦截器

## Jwt登录认证

JWT令牌由用英文句点（.）分隔的Header（头部）、Payload（载荷）、Signature（签名）三段信息组成：Header是经Base64Url编码的JSON对象，主要说明令牌类型为JWT以及所用的签名算法（比如HS256）；Payload同样是经Base64Url编码的JSON对象，用来存放用户ID、过期时间等不涉及敏感信息的声明内容；Signature则是按照Header里指定的算法，把编码后的Header和Payload与密钥（或密钥对）结合加密生成的签名，目的是验证令牌有没有被篡改、是否真实有效，这三段内容共同构成了可用于数据传输的JWT字符串。

### JwtUtils

```java
package xyz.cmcy.pojo;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.SignatureAlgorithm;
import java.util.Date;
import java.util.Map;

/**
 * JWT令牌操作工具类
 */
public class JwtUtils {

    // 签名密钥，与测试类中保持一致
    private static final String SECRET_KEY = "Y2hpbWluZ2NoYW5neWlu";

    // 令牌过期时间：12小时（单位：毫秒）
    private static final long EXPIRATION_TIME = 12 * 3600 * 1000;

    /**
     * 生成JWT令牌
     * @param claims 要包含在令牌中的自定义数据
     * @return 生成的JWT令牌字符串
     */
    public static String generateToken(Map<String, Object> claims) {
        // 计算过期时间：当前时间 + 12小时
        Date expirationDate = new Date(System.currentTimeMillis() + EXPIRATION_TIME);

        // 构建并返回JWT令牌
        return Jwts.builder()
                .signWith(SignatureAlgorithm.HS256, SECRET_KEY)  // 使用HS256算法和指定密钥签名
                .addClaims(claims)  // 添加自定义数据
                .setExpiration(expirationDate)  // 设置过期时间
                .compact();  // 生成令牌字符串
    }

    /**
     * 解析JWT令牌
     * @param token 要解析的JWT令牌字符串
     * @return 令牌中包含的自定义数据（Claims对象）
     */
    public static Claims parseToken(String token) {
        // 解析令牌并返回其中的自定义数据
        return Jwts.parser()
                .setSigningKey(SECRET_KEY)  // 指定签名密钥（必须与生成时使用的一致）
                .parseClaimsJws(token)  // 解析令牌
                .getBody();  // 获取包含自定义数据的Claims对象
    }
}
```

## 请求拦截器

Filter差不多相当于全局的过滤任何请求都会被拦截,依赖Servlet容器

而后面说的Interceptor仅仅是会拦截Spring容器当中的内容

所以姑且可以理解为Filter包含Interceptor

### TokenFilter

注意一下引入的新装饰器@WebFilter即可这里可以匹配拦截的路径这里的配置是一个全局的然后在下面排除登录或者是注册的路径

需要注意的是这个是通过Servlet 规范的机制生效的,跟Spring中的IOC容器没关系

核心是`@WebFilter(urlPatterns = "/*")`注解的作用：它声明该类是一个过滤器，并指定拦截所有请求（`/*`）

```java
package xyz.cmcy.filter;

import jakarta.servlet.*;
import jakarta.servlet.annotation.WebFilter;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.extern.slf4j.Slf4j;
import xyz.cmcy.pojo.JwtUtils;

import java.io.IOException;

@Slf4j
@WebFilter(urlPatterns = "/*")
public class TokenFilter implements Filter {
    @Override
    public void init(FilterConfig filterConfig) throws ServletException {
        Filter.super.init(filterConfig);
    }

    @Override
    public void doFilter(ServletRequest servletRequest, ServletResponse servletResponse, FilterChain filterChain) throws IOException, ServletException {
        HttpServletRequest request = (HttpServletRequest) servletRequest;
        HttpServletResponse response = (HttpServletResponse) servletResponse;
        //1.获取请求路径
        String requestURI = request.getRequestURI();
        //2.判断是否是登录请求,如果路径中包含 /login,说明是登录操作,放行
        if (requestURI.contains("/login")) {
            log.info("登录请求!放行!!!");
            filterChain.doFilter(request, response);
            return;
        }
        //3.获取请求头中的token
        String token = request.getHeader("token");
        //4.判断token是否存在,如果不存在,说明有就几乎没有登录,返回错误信息
        if (token == null || token.isEmpty()) {
            log.info("令牌为空响应,401");
            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
            return;
        }
        //5.如果token存在,校验令牌,如果校验失败,返回错误信息
        try {
            JwtUtils.parseToken(token);
        } catch (Exception e) {
            log.info("令牌非法,401");
            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
            return;
        }
        //6.校验通过放行
        log.info("令牌合法,放行!!!");
        filterChain.doFilter(request, response);
    }

    @Override
    public void destroy() {
        Filter.super.destroy();
    }
}

```

### WebConfig

这就是为什么上面的Interceptor拦截器注释掉了获取URI以及判断URI中是否包含登录或者是注册路径

就是因为在这里的

这个跟上面的不一样,这个是注册到Spring的IOC容器中的

被`@Configuration`标记的`WebConfig`类实现`WebMvcConfigurer`接口，在重写的`addInterceptors`方法中通过`InterceptorRegistry`注册`TokenInterceptor`，并配置拦截所有请求（排除登录接口）；Spring 启动时加载该配置类，使拦截器按设定规则全局生效。

```java
package xyz.cmcy.config;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.InterceptorRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;
import xyz.cmcy.interceptor.TokenInterceptor;

@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Autowired
    private TokenInterceptor tokenInterceptor;

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(tokenInterceptor).addPathPatterns("/**").excludePathPatterns("/login");//拦截所有请求
    }
}
```

这个 AOP 切面无需手动注入就能使用，因为`@Component`注解已将`RecordTimeAspect`注册到 Spring IOC 容器，`@Aspect`又声明其为切面类并结合`@Around`定义了切入点（拦截`DeptServiceImpl`的所有方法）与增强逻辑；Spring 启动后会自动识别容器中的该切面并解析配置，当目标方法执行时，通过动态代理自动触发切面的增强逻辑，无需在其他类中显式注入切面即可生效。

```java
@Component
@Aspect //当前类为切面类
@Slf4j
public class RecordTimeAspect {

    @Around("execution(* com.itheima.service.impl.DeptServiceImpl.*(..))")
    public Object recordTime(ProceedingJoinPoint pjp) throws Throwable {
        //记录方法执行开始时间
        long begin = System.currentTimeMillis();

        //执行原始方法
        Object result = pjp.proceed();

        //记录方法执行结束时间
        long end = System.currentTimeMillis();

        //计算方法执行耗时
        log.info("方法执行耗时: {}毫秒",end-begin);
        return result;
    }
}
```
