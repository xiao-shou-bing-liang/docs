## Linux 之父——Linus

李纳斯·托沃兹（Linus Torvalds）是 Linux 之父。1991年，正在赫尔辛基大学读书的李纳斯·托沃兹自己动手写了一个电脑操作系统，取名 Linux，并公开了源代码。他的初衷是开发任何人都可以使用的操作系统，愿意接受别人在免费公开的前提下提供的修正、补充和增强。在互联网的帮助下，Linux 的开发群和用户群迅速增长，从开发者工具箱演变为能够与微软视窗和Unix抗衡的操作系统。今天，Linux 已经变成了具有强大吸引力的平台。李纳斯·托沃兹十岁的时候就开始编程。爷爷为他带回家一台 Commodore 机器，李纳斯立即开始使用它来编写自己的计算机游戏。当他买回第一部PC机时，觉得 DOS 不如学校实验室的 Unix 系统好用，但苦于 Unix 没有在微机上运行的版本（太贵了！），因此他决定写一个自己的操作系统。

Ubuntu 的 Live Server（服务器版）和 Desktop（桌面版）在多个方面存在显著区别，以下是对两者的详细比较：

|  | **Ubuntu Live Server（服务器版）** | **Ubuntu Desktop（桌面版）** |
| --- | --- | --- |
| **用户界面** | 无图形用户界面，直接进入命令行界面，适合服务器管理和配置。 | 拥有完整的图形用户界面（GUI），包括窗口管理器、任务栏、桌面背景等，适合日常使用和开发。 |
| **软件安装** | 默认安装较少的软件包，主要关注服务器相关组件，如Web服务器、数据库服务器等。用户可根据需求安装其他软件。 | 默认安装大量桌面应用程序，如办公套件、图像处理工具、网络浏览器等，满足日常办公、娱乐和学习需求。 |
| **硬件需求** | 对硬件要求较低，内存和存储空间需求较小，适合在资源受限的环境中运行。 | 对硬件要求较高，尤其是内存和存储空间，以支持图形界面和众多应用程序的运行。 |
| **使用场景** | 主要用于服务器环境，如Web服务器、数据库服务器、FTP服务器等。也适合需要远程管理和配置的场景。 | 适用于个人用户和开发者，提供用户友好的图形界面和丰富的桌面应用程序支持。适用于日常办公、开发、学习和多媒体娱乐等场景。 |
| **更新与维护** | 更新和维护主要通过命令行进行，需要一定的技术背景。 | 提供图形化的更新和维护工具，操作相对简单。 |
| **网络配置** | 网络配置通常通过命令行完成，支持DHCP或静态IP配置。 | 提供图形化的网络配置工具，方便用户进行网络设置。 |
| **安全性** | 由于没有图形界面，减少了被攻击的风险。但服务器本身的安全性仍需用户通过配置和管理来保障。 | 图形界面可能增加一定的安全风险，但Ubuntu Desktop也提供了多种安全机制来保护用户数据。 |

## 物理机安装

### **制作安装盘**

- 先准备一块读写速度不拉胯的u盘
- 直接下载图吧工具箱，它可以满足你的一切装机需求
- 打开图吧工具箱——其他工具——ventoy2disk
- 将u盘插入电脑，使用 ventoy2disk 将其制作为安装盘
- 把ISO镜像文件放入u盘

### **进入 BIOS 或者 UEFI (以下使用 BIOS 说明)**

- 在开机时，不同型号主板要使用不同的键位进入 BIOS，我那个 x79 双路老毕登主板就是 del 键（狂摁即可）进入BIOS，现在这个是 f2 进入
- 进入到 BIOS 里就要使用 Boot Manager 来选择优先进入哪个系统，此时我们选择将 u 盘放在第一位
- 进入u盘选择要安装的操作系统

至于安装过程就跟上面虚拟机流程一样的，都有 GUI 界面随便怎么都装上了，但是物理机安装的话需要解决计时器问题还有 grub 引导等问题。在此不多赘述
