# 攻防与终端安全学习报告

## 一、攻防技术概述

网络安全攻防是保障信息系统安全的核心环节，涉及网络层、应用层、主机层等多个维度。现代攻防对抗呈现出"技术复杂化、手段隐蔽化、对抗持续化"的特点，要求安全人员具备"知攻善防"的综合能力。

攻防技术学习需遵循"理论筑基-实践强化-场景应用"的路径，重点掌握攻击手段的技术原理、防御措施的实施方法，以及安全事件的处置流程，构建完整的安全认知体系。

## 二、常见攻击手段与原理

### 2.1 网络层攻击

| 攻击类型 | 技术原理 | 典型特征 | 复现环境 |
| --- | --- | --- | --- |
| **DDoS攻击** | 利用大量僵尸主机发送海量请求，耗尽目标资源 | 带宽突增、服务器响应缓慢 | 虚拟机集群、hping3工具 |
| **ARP欺骗** | 伪造IP与MAC映射关系，篡改网络通信路径 | 网络中断、数据被监听 | 局域网环境、arpspoof工具 |
| **DNS劫持** | 篡改DNS解析结果，将域名指向恶意IP | 访问异常网站、数据泄露 | DNS服务器、dig命令 |

### 2.2 应用层攻击

| 攻击类型 | 技术原理 | 危害程度 | 典型案例 |
| --- | --- | --- | --- |
| **SQL注入** | 插入恶意SQL语句操纵数据库 | 高 | 未过滤用户输入导致数据泄露 |
| **XSS攻击** | 注入恶意脚本获取用户信息 | 中高 | 盗取Cookie实现会话劫持 |
| **CSRF攻击** | 利用用户身份执行非预期操作 | 中 | 伪造转账请求完成非授权交易 |

### 2.3 主机层攻击

- **缓冲区溢出**
    
    原理：输入数据超过缓冲区容量，覆盖相邻内存区域，改写程序执行流程
    
    防御关键点：输入验证、使用安全函数、内存保护机制
    
- **权限提升**
    
    原理：利用系统漏洞或配置缺陷，从低权限账户获取管理员权限
    
    常见途径：内核漏洞利用、SUID文件滥用、服务配置错误

## 四、终端安全核心要点

### 4.1 终端安全威胁图谱

终端面临的安全威胁主要包括：

- **恶意代码感染**：病毒、蠕虫、勒索软件等
- **账户安全风险**：弱密码、暴力破解、凭证窃取
- **数据泄露风险**：敏感信息未加密、USB设备滥用
- **系统漏洞利用**：未修复的操作系统及软件漏洞
- **非法接入风险**：未授权设备接入、物理接触攻击

### 4.2 终端安全防护目标

终端安全防护需实现"四个保障"：

1. 保障终端身份可信
2. 保障系统运行安全
3. 保障数据存储安全
4. 保障操作行为可控

## 五、操作系统安全配置

### 5.1 Windows系统安全加固

| 安全维度 | 关键配置项 | 加固建议 |
| --- | --- | --- |
| 账户安全 | 管理员权限、密码策略 | 禁用默认管理员、启用强密码策略 |
| 系统服务 | 不必要服务、端口 | 关闭Telnet、FTP等非必要服务 |
| 安全策略 | UAC、防火墙 | 启用UAC、配置入站/出站规则 |
| 日志审计 | 登录日志、操作记录 | 开启安全日志、设置日志留存期 |

### 5.2 Linux系统安全加固

```bash
# 基础安全配置示例
# 1. 设置密码策略
sed -i 's/PASS_MAX_DAYS\\t99999/PASS_MAX_DAYS\\t90/' /etc/login.defs

# 2. 禁用root远程登录
sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config

# 3. 配置防火墙
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
iptables -A INPUT -j DROP

# 4. 启用日志审计
systemctl start auditd
systemctl enable auditd

```

### 6.2 终端检测与响应（EDR）

EDR技术核心能力：

- 实时行为监控：进程活动、网络连接、文件操作
- 异常行为分析：基于基线的异常检测、AI威胁识别
- 快速响应处置：隔离感染终端、终止恶意进程
- 全面溯源分析：攻击路径还原、影响范围评估
